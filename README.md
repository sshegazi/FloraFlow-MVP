# FloraFlow MVP 🌸
**Course:** Software Engineering MVP Project
**Prepared by:** Sarah Mohammed
**University:** Prince Sattam bin Abdulaziz University

## Project Overview
FloraFlow is a logistics and management system designed for floral businesses to manage events (like weddings and graduations) and track flower inventory freshness.

## Key Features (MVP)
- **Role-based Authentication:** Separate dashboards for Admins and Customers.
- **Event Calendar:** Customers can schedule and view floral events.
- **Inventory Tracking:** Real-time monitoring of stock with freshness alerts.

## Technical Setup (How to run locally)
1. Clone the repository.
2. Open your terminal in the project folder.
3. Run `npm install` to install dependencies.
4. Run `npm run dev` to launch the local server.
5. Open `http://localhost:5173` in your browser.
